 lightbulb Comment ça marche
  • Ajouter : un lot de bulk acheté (ex. 3 000 cartes pour 30 €) ou les cartes de votre collection (0 €). Il apparaît dans les achats et le registre comme les autres achats.
  • Vendre un lot : choisissez la catégorie, le nombre de cartes (ou le poids) et le prix du lot. Les cartes les plus anciennes partent en premier, et le bénéfice utilise leur coût réel.
  • Les ventes de bulk entrent dans le CA, l'URSSAF, le livre des recettes et les statistiques, comme les autres ventes.
  • Les catégories apparaissent aussi dans l'inventaire (type « Bulk »).
